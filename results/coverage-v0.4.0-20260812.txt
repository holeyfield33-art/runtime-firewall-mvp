Known bypasses (documented for future work):
  1. Bracket-notation eval:   this["ev"+"al"]  → needs AST or V8 Inspector
  2. String concatenation:    global["ev"+"al"] → needs taint tracking
  3. Variable-alias eval:     const fn = eval; fn("code") → needs runtime Proxy
  4. Prototype chain access:  Object.getPrototypeOf(eval).constructor → needs runtime instrumentation

Note: Array join reassembly (["ch","ild"].join("")) bypasses per-module isolation; may be caught by cross-module state in practice.

All bypasses require runtime (dynamic) analysis. Static analysis has fundamental limits.
Behavioral detection mitigates bypasses by flagging dangerous ACTION SEQUENCES
rather than specific strings, providing defense-in-depth.
